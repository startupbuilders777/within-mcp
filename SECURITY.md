# Security

To report a security problem with the within MCP server or with this repo, write to hello@shopwithin.co. Please do not open a public issue for it. We read every report.

The server only reads public catalog data. It takes no login and asks for no personal details. It counts each call to the tools (which tool, when, how long, whether it worked, how many results, which app called and the country of the computer that called) and never keeps what was asked, a photo or an IP address.
